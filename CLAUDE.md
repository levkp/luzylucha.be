# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Luzylucha.be

This is the source code for the luzylucha.be website, made using Hugo. Luzy Lucha makes artisanal embroideries, and this
website showcases some of her works, as well as practical information for example contact information and how to
buy her products.

## Design

You are free to choose the overall design of the website, so long it uses the following elements: `#cc0000` and `#f9b34b`
as primary colors, and `#efddce` as accent color. You can find her business card (front and back image) under
`themes/assets/img/card-front.png` and `themes/assets/img/card-back.png` that you can use for inspiration when designing
the site.

Focus on the product - embroideries, patchworks, etc. - to design visual elements.

## Code changes

When making changes, make sure to:

- never include JavaScript (this site serves static HTML and CSS only)
- all text must be localized in three languages: English, Dutch and French
